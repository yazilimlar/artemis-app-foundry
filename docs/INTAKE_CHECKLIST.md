# Application Intake Checklist

## Identification
- [ ] Assign stable app ID
- [ ] Extract title and version
- [ ] Identify product family
- [ ] Select repository and Vercel project

## Technical
- [ ] Validate HTML/JavaScript
- [ ] Inventory external dependencies
- [ ] Detect embedded assets and data
- [ ] Test desktop/mobile
- [ ] Check browser console
- [ ] Test exports and print views

## Data and security
- [ ] Identify project/client data
- [ ] Identify PII, claims, costs, and locations
- [ ] Sanitize demo datasets
- [ ] Confirm no secrets
- [ ] Assign exposure level

## Licensing
- [ ] Record third-party sources
- [ ] Preserve attribution
- [ ] Confirm commercial-use rights

## Productization
- [ ] Normalize name
- [ ] Add ARTEMIS/AGOraXAI navigation
- [ ] Add footer, privacy, terms, safety language
- [ ] Add analytics and lead attribution
- [ ] Add registry entry

## Deployment
- [ ] Deploy preview
- [ ] Run acceptance tests
- [ ] Approve production
- [ ] Attach domain
- [ ] Verify DNS and SSL
- [ ] Record SHA and URL
