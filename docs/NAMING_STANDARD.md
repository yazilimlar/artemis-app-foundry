# Naming and Directory Standard

Display name: `ARTEMIS <Capability Name>`
Repository: `artemis-<capability>`
App ID: lowercase kebab case
Archive: `archive/YYYY-MM-DD/<normalized-original-filename>`
Canonical standalone entry: `public/app/index.html`

Each release records:
- product name
- app ID
- version/RC
- family
- exposure
- safety classification
- source filename
- Git SHA
- deployment URL
- verification date
